# Google-vs--facebook-Campaign-Analysis

Personal data analysis project focused on marketing campaign performance, CPC and CPA metrics.
📊 Digital Marketing Data Analysis Dashboard

This personal data analysis project was developed in Excel to compare the performance of Google Ads and Facebook Ads campaigns. The goal was to transform raw marketing data into actionable insights through Pivot Tables, Pivot Charts, and interactive dashboards.

🚀 Technologies Used
Microsoft Excel
Pivot Tables
Pivot Charts
Calculated Fields (CPC and CPA)
Interactive Dashboard

📈 Project Steps
Data cleaning and exploration.
Creation of Pivot Tables for data aggregation.
Calculation of key performance indicators:
CPC (Cost Per Click)
CPA (Cost Per Acquisition)
Development of interactive dashboards for data visualization.
Performance comparison between Google Ads and Facebook Ads campaigns.
