# Google-vs--facebook-Campaign-Analysis

# 📊 Digital Marketing Data Analysis Dashboard
### Google Ads vs. Facebook Ads | Marketing Campaign Performance Analysis

## 📌 Project Overview

This personal data analysis project was developed in **Microsoft Excel** to compare the performance of Google Ads and Facebook Ads campaigns.

The main objective was to transform raw marketing data into actionable insights using Pivot Tables, Pivot Charts, calculated fields, and interactive dashboards.

The analysis focuses on key performance indicators (KPIs), advertising costs, audience segmentation, and campaign performance to support data-driven marketing decisions.

---

## 🛠️ Technologies & Tools

- **Microsoft Excel**
- **Pivot Tables**
- **Pivot Charts**
- **Calculated Fields**
- **Interactive Dashboards**
- **Marketing Performance Metrics (CPC and CPA)**

---

## ⚙️ Project Workflow

The project was developed through the following steps:

1. **Data Cleaning & Exploration** — Preparing and exploring the raw marketing dataset.
2. **Data Aggregation** — Creating Pivot Tables to summarize campaign performance.
3. **KPI Calculation** — Calculating key marketing metrics, including CPC and CPA.
4. **Data Visualization** — Developing Pivot Charts to identify trends and patterns.
5. **Dashboard Development** — Building interactive dashboards to present the results clearly.
6. **Performance Analysis** — Comparing Google Ads and Facebook Ads campaigns to identify optimization opportunities.

## 1. 🔎 Google Ads Performance Analysis

### 1.1. CPC by Subchannel

![Google Ads CPC by Subchannel](https://github.com/user-attachments/assets/3721173f-3ee9-4b45-a72e-ec1638853af4)

**Key Insights:**
- **Brand** campaigns presented the lowest Cost Per Click (CPC).

### 1.2. Advertising Spend by Subchannel

![Google Ads Spend by Subchannel](https://github.com/user-attachments/assets/4f2b186f-1182-445e-b522-305e23abfd02)

- **Competitor** campaigns received the smallest share of investment.
- Evaluating the relationship between spending and campaign results can help improve budget allocation.

### 1.3. CPC by Age Group and Device

![Google Ads CPC by Age and Device](https://github.com/user-attachments/assets/4181fcf9-5787-4896-b51b-db58d074efa5)

- **Mobile devices** generated the highest traffic volume.

- Analyzing CPC alongside conversion rates can help identify the most efficient audience and device combinations.

# 🎯 Key Performance Indicators (KPIs)

The project focuses on the following marketing performance indicators:

| KPI | Description |
|---|---|
| **CPC — Cost Per Click** | Measures the average cost of generating a click on an advertisement. |
| **CPA — Cost Per Acquisition** | Measures the average cost of generating a desired acquisition or conversion. |
| **Advertising Spend** | Measures the total investment allocated to advertising campaigns. |
| **Impressions** | Measures how many times advertisements were displayed. |
| **Clicks** | Measures the number of interactions with advertisements. |
